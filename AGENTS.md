# Project & Agent Instructions

## Toolchain & Verification
- **Project Type & Stack:** Browser-based HTML/CSS/JS single-file tool (Bootstrap 5 + Font Awesome 6 CDN)
- **Build & Test Command:** `open semipaint24.html` — no build step; open the file in any modern browser to verify
- **Emulator Verification:** For CoCo binaries exported by the tool (`.S24`, `.BAS`, `.asm`), load into `xroar-dev` (`~/.xroar`) and verify display at $0400 before marking a task complete.
- **CoCo Hardware Corpus:** For any 6809/6309 assembly, MC6847 VDG, MC6883 SAM, SG24 byte format, or BASIC export work, read from `$HOME/CoCo-Skills` (pre-installed by the container setup script—do NOT re-clone if that folder exists). Only if `$HOME/CoCo-Skills` is missing, run `gh repo clone CarlosCamacho/CoCo-Skills "$HOME/CoCo-Skills" -- --depth 1`. Start with `coco-router/SKILL.md` and load only the specific child skill files needed for this task.

## Standing Rules
- **SG24 Byte Format:** `D7=1 · D6–D4=color(0–7) · D3=left · D2=right · D1D0=11` for colored cells; `$20` for black. Color 0=Green, not Black. Black = ASCII space `$20`.
- **Internal Pixel Encoding:** `ep(c,on)=(c&7)<<1|(on?1:0)` — uniform bit1 model for both left and right slots.
- **Single-File Constraint:** All code, styles, and logic must remain in `semipaint24.html`. Do not split into separate JS/CSS files.
- **Context Hygiene:** Keep edits focused strictly on the assigned task. Do not refactor or rewrite unrelated sections.
- **CoCoSDC Required:** Any CoCo program or loader generated by this tool must support CoCoSDC (and DriveWire via DSKCON).

## Mandatory Session Handoff Rule
- Before ending your session, closing out, or opening a PR, you MUST overwrite `HANDOFF.md` in the repo root (strictly under 35 lines) with:
  1. Current branch/commit status and what builds cleanly
  2. Immediate next backlog task
  3. Dead ends / failed approaches tried in this session that must not be repeated
- Always include the updated `HANDOFF.md` in your commit/PR.
